# Отчет по Docker

Сборка и запуск:

- Сборка: `docker build -t week10-app weeks/week-10`
- Запуск: `docker run -p 8127:8127 week10-app`

Размер (image size):

- Базовый одноступенчатый образ (single stage): около 260 MB.
- Оптимизированный multi-stage образ: около 150 MB.
- Экономия размера: около 110 MB.

Слои (layers):

- Отдельный слой для `COPY requirements.txt` и `RUN pip install` помогает использовать кеш зависимостей.
- Слой `COPY . .` обновляется чаще, но не ломает кеш для установленных библиотек.
- Multi-stage уменьшает итоговый размер: зависимости собираются в builder-слое, а в runtime попадает только нужный результат.
